# Linux Aaron — Advertising Portfolio

Eine eigenständige, statische Portfolio-/Werbeseite für **Joscha Aaron Schmidt / linux_aaron**.

## Zweck

Die Seite präsentiert Leistungen rund um:

- Landingpages und moderne Websites
- individuelle Webentwicklung
- technische Webprojekte
- Linux, OSINT und Web Security
- Git/GitHub und Cloud-Deployment

## Technik

- HTML5
- CSS3
- Vanilla JavaScript
- responsive / mobile-first Layout
- keine externen JavaScript-Abhängigkeiten

Die Gestaltung ist eine eigenständige Umsetzung mit Cyber-/Terminal-Ästhetik und übernimmt keine personenbezogenen Inhalte des ursprünglichen Templates.
